# Reporting Security Issues

If you believe you have found a security vulnerability in YourPeer,
GoGetta/SSTT, the Streetlives API or our chatbot, please let us know
right away.

**Please do not report it through a public GitHub issue.** Email us at
`security@streetlives.nyc`.

To help us act quickly, please include:

- What kind of issue it is
- The site, repository or endpoint affected
- Step-by-step instructions to reproduce it
- What impact you think it has

We will investigate all legitimate reports and do our best to fix the
problem quickly. We do not currently offer a paid bug bounty, but we are
glad to credit you once a fix is live.
